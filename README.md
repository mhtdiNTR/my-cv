# أحمد سعيد | السيرة الذاتية

موقع سيرة ذاتية من صفحة واحدة بالعربية (HTML / CSS / JavaScript) بدون أي مكتبات.

## التشغيل
افتح `index.html` في المتصفح مباشرة.

## النشر على GitHub Pages
Settings ← Pages ← Deploy from branch ← `main` / `(root)`.

## التعديل
- المحتوى: `index.html`
- التصميم والألوان: `css/style.css` (المتغيرات في أعلى الملف)
- البريد يُعدَّل في مكان واحد: رابط `mailto:` داخل قسم «تواصل معي».
- الصور والملفات (صورة شخصية، CV بصيغة PDF): ضعها في `assets/`.
